## Контекст

Создаём GIS-сервис для нужд провайдера интернет. Разработка ведётся в **сервисной архитектуре**, всё разворачивается **в Docker**.

## Цель

Веб-приложение для сетевого инженера, в котором он на карте:

- отмечает (создаёт / изменяет / удаляет) объекты инфраструктуры;
- видит проложенные линии оптоволокна, трассы, столбы, дома абонентов, активное сетевое оборудование и т.п.

## Функциональные требования (первичные)

### Отображение (карта)
- Интерактивная карта с отрисовкой объектов: столбы, линии оптики, трассы, дома абонентов, активное сетевое оборудование.
- Включение / выключение отображения объектов по слоям (visibility toggle).

### Управление доступом
- Разделение на уровне доступа:
  - отображение объектов (видимость слоёв/объектов);
  - изменение объектов (создание, редактирование, удаление).
- Разграничение прав должно строиться на уровне **типов объектов** (слоёв) и, при необходимости, более тонко.

### Аутентификация и авторизация
- Сервис пользователей **существует отдельно** и в рамках текущей разработки **не подключается**.
- Используется **JWT**.
- Вместо сервиса авторизации — **заглушка с моками** (`mock-auth`): выдача JWT для заранее заготовленных пользователей с разными разрешениями.
- API доверяет содержимому JWT (claims): `sub` (идентификатор пользователя), `name`, `role`, `permissions`. Логика прав строится только на основе claims, чтобы подключение реального сервиса пользователей не потребовало переработки бизнес-логики.

## Технологические решения (согласовано)

| Область      | Решение                                        |
|--------------|------------------------------------------------|
| Карта        | MapLibre GL + векторные тайлы (self-hosted)    |
| Бэкенд API   | Node.js (NestJS)                               |
| Фронтенд     | Vue 3 + Vite                                   |
| Хранилище    | PostgreSQL + PostGIS                           |
| Инфраструктура | Docker Compose (все сервисы в контейнерах)    |

## Состав сервисов (черновик)

| Сервис       | Роль                                                    |
|--------------|---------------------------------------------------------|
| `web`        | SPA для сетевого инженера (Vue 3 + MapLibre)           |
| `api`        | Бизнес-логика, CRUD объектов, RBAC по claims JWT       |
| `tiles`      | Сервер векторных тайлов (Martin)                       |
| `db`         | PostgreSQL + PostGIS, хранение геоданных               |
| `mock-auth`  | Заглушка аутентификации, выдача JWT тестовым юзерам    |
| `proxy`      | Обратный прокси, единая точка входа                    |

## Ограничения и замечания

- Все сервисы обязательно в Docker.
- Стек предпочтительно лёгкий, но без жёсткого дефицита ресурсов (сервер: 11 ГБ RAM, ~55 ГБ свободного диска после очистки).
- Документация и планирование ведутся в каталоге `docs/`.
