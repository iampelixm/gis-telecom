# Документация проекта

GIS-сервис для нужд провайдера интернет. Всё в Docker.

## Структура

```
docs/
  DMAP.md         — единый обзор: возможности, архитектура, схемы Mermaid, руководство пользователя
  00-status.md   — сжатое состояние проекта (начинать здесь для контекста)
  01-tasks/       — исходные задания, требования
  02-architecture/— сервисная архитектура, схемы, решения
  03-objects/     — каталог объектов и слоёв (столбы, линии, дома, оборудование)
  04-access/      — роли, права, матрица доступа
  05-roadmap/     — план работ, статусы
  06-decisions/   — ADR, зафиксированные архитектурные решения
```

## Быстрый старт чтения

0. `00-status.md` — сжатое состояние проекта.
1. `01-tasks/initial-task.md` — исходное задание.
2. `05-roadmap/roadmap.md` — текущий план и статусы.
3. `02-architecture/services.md` — состав сервисов.
